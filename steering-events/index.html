    Was dieser Test aussagt

    Media Session zeigt an, ob der Browser die Schnittstelle annimmt. Erst ein Ereignis beim echten Lenkraddruck beweist eine Weiterleitung. „Tastatur“ ist ein DOM-Ereignis, „Medienaktion“ ein Media-Session-Aufruf; beides kann auch durch andere Bedienelemente entstehen. Unterstütztes „togglemicrophone“ bedeutet nicht, dass Teslas Mikrofontaste damit verbunden ist.

    Medienereignisse werden nur angezeigt: Sie starten weder Ton noch Aufnahme. Die Registrierung kann vorübergehend beeinflussen, wohin Tesla Medienbefehle leitet. Bei Tabwechsel wird der Testton gestoppt und die Medienregistrierung entfernt. Zum erneuten Testen danach diese Seite neu laden. Kein Dauer- oder Stille-Audio.
